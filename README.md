# 信号与系统实验
这是东南大学信号与系统实验课程中各实验题目的Python实现版。原课程要求使用MATLAB，在本项目中则使用Python实现了所有实验题目。

## 如何运行
1. 克隆项目
```bash
git clone https://github.com/SFM05/Signal-and-System-Experiment.git
cd Signal-and-System-Experiment
```
2. 安装依赖

Windows:
```bash
python -m venv .venv
.venv/Scripts/activate
pip install -r requirements.txt
```

Linux/Mac OS:
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
3. 运行代码
```bash
python exp1-信号的运算\Q1-信号的基本运算.py
```
